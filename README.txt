BIOFROST — сайт кофейни-пекарни

ЗАПУСК
1. Распакуйте архив.
2. Откройте папку biofrost-website.
3. Запустите index.html в браузере.
   Для локальной разработки можно открыть папку в VS Code и использовать Live Server.

ФАЙЛЫ
- index.html — структура сайта и секции.
- styles.css — адаптивный дизайн и анимации.
- script.js — категории меню, мобильная навигация и форма.

ВАЖНО
Форма предзаказа пока демонстрационная: проверяет заполнение и показывает сообщение, но никуда не отправляет.
Подключение Telegram-бота и безопасное хранение токена — отдельный следующий этап.
Для отображения фотографий требуется подключение к интернету (изображения загружаются с Unsplash).
В меню замороженной продукции цена круассана классического не указана в исходных данных, поэтому сайт показывает «Цена не указана».
