BIOFROST — сайт кофейни-пекарни

ЗАПУСК
1. Распакуйте архив.
2. Откройте папку biofrost-website.
3. Запустите index.html в браузере.
   Для локальной разработки можно открыть папку в VS Code и использовать Live Server.

ФАЙЛЫ
- index.html — структура сайта и секции.
- styles.css — адаптивный дизайн и анимации.
- script.js — категории меню, мобильная навигация и отправка формы.
- functions/api/order.js — серверная отправка предзаказа в Telegram (Cloudflare Pages Functions).

ВАЖНО
ФОРМА И TELEGRAM (Cloudflare Pages)
Форма отправляет предзаказ через серверную функцию /api/order. Токен не хранится в браузере.
В Cloudflare Dashboard откройте Workers & Pages → ваш Pages-проект → Settings → Variables and Secrets.
Добавьте два значения для Production (и Preview, если тестируете Preview):
- TELEGRAM_BOT_TOKEN — новый токен бота, полученный после /revoke в @BotFather.
- TELEGRAM_CHAT_ID — ваш Telegram chat ID.
Сохраните настройки и выполните новую сборку/деплой сайта. Не вставляйте токен в index.html или script.js.
Перед отправкой заявки откройте чат с ботом и нажмите Start, иначе бот не сможет написать вам первым.
Проверьте форму после публикации на домене Cloudflare Pages. При локальном открытии index.html напрямую API не работает.
Для отображения фотографий требуется подключение к интернету (изображения загружаются с Unsplash).
В меню замороженной продукции цена круассана классического не указана в исходных данных, поэтому сайт показывает «Цена не указана».


Обновление: на первом экране добавлен зацикленный фоновый видеоролик кофейной тематики. Видео загружается с Pexels; для воспроизведения требуется интернет. Есть постер-заставка на случай медленной загрузки и отключение видео при настройке reduced motion.
